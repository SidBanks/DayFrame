# DayFrame

DayFrame is an intelligent decision-support system that helps people
intentionally invest their finite time.

Unlike traditional calendar applications, DayFrame separates **reality**
from **intention**.

-   **Reality** is represented by **Commitments**.
-   **Intention** is represented by **Goals**.

The scheduling engine continuously reconciles both, helping users make
better decisions while minimizing the effort required to plan.

------------------------------------------------------------------------

# Project Philosophy

DayFrame is built around a simple belief:

> People do not need another calendar. They need help deciding what
> deserves their limited time.

Every recommendation, interaction, and visualization exists to support
that purpose.

------------------------------------------------------------------------

# Core Experiences

DayFrame consists of three primary experiences.

## Planner

Provides orientation.

Answers:

-   Where am I?
-   What must happen?
-   What should I work on?

The Planner is centered on the Month Planner and Daily Workspace.

------------------------------------------------------------------------

## Daily Workspace

Provides execution.

Users can:

-   Complete Commitments
-   Complete Goal Allocations
-   Capture Found Time
-   Record Notes
-   Review Capacity
-   Adjust the current day with minimal friction

------------------------------------------------------------------------

## Summary

Provides understanding.

The Summary helps users reflect on and improve how they invest their
time.

It includes:

-   Capacity
-   Goal Progress
-   Goal Creation & Management
-   Allocation Strategies
-   Pattern Library
-   Retrospectives
-   Notes

# Development Philosophy

DayFrame is developed using an experience-first process.

Experience

↓

Specification

↓

Engine Contract

↓

Implementation

↓

Testing

The scheduling engine exists to fulfill the user experience defined by
the specifications.

------------------------------------------------------------------------

# Current Status

DayFrame is currently transitioning from architectural discovery to
formal product specification.

The core user experience is being defined before implementation,
beginning with the Month Planner Design Specification.

------------------------------------------------------------------------

# Guiding Principle

> DayFrame should help people intentionally invest their finite time
> while reducing the stress and cognitive burden of planning.

Every feature should make planning feel calmer, simpler, and more
trustworthy.
