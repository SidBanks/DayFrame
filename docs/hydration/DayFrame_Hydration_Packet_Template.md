# DayFrame Hydration Packet

## Purpose

This document serves as a conversation handoff ("hydration packet") so a
new chat can resume work with minimal context loss.

## Structure

-   Project State
-   Product Philosophy
-   UX Decisions
-   Engine Status
-   Outstanding Questions
-   Next Actions

## Notes

Hydration packets are intended to be living documents. Each major design
or implementation milestone should produce a new packet rather than
continuously editing an old one.
