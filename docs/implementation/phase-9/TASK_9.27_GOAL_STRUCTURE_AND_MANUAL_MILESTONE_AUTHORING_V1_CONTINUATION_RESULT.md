## Relationship and Milestone behavior

Containment says which Goal contains which Subgoal and requires an intentional required/optional choice. Contribution remains directional and non-aggregating. Prerequisite direction is dependent Goal to the Goal or owned Milestone supplying the condition. Controls explain that Structure does not aggregate Requested Time, transfer measured Progress, inherit Priority or complete a parent. A Milestone remains a manual checkpoint, not scheduled work or Goal completion.

Editing a relationship retains kind and endpoints; this slice offers supported requiredness/strength semantics under the fixed condition appropriate to that endpoint. It does not disguise retargeting or kind conversion as editing. The canonical owner rejects self/duplicate/cyclic/multiple-parent structures while allowing lawful contribution cycles. Retirement is explicit and retains exact history and endpoint Goals.

Milestone patches contain only intentional metadata/state changes. Optional date clearing uses null; untouched values are omitted. The owner allocates identity, provenance, revision and times. Metadata-only or same-state edits preserve lifecycle facts; combined changes use the single existing command. Referenced retirement rejection is described as returned, without fabricating a blocking record or auto-retiring dependencies. Exact previous revisions are read only on disclosure, without substituting the current record.

## Context, failure handling and navigation

The existing ephemeral app-owned editing context now holds per-owner/per-Goal Structure editor state: draft/base/expected revision, current editor, search/reveal/disclosure, busy flag, accepted identity/revision/outcome and focus intent. A WeakMap supplies presentation owner identity only. No context is durable. Related-Goal navigation saves/restores the original Goal view snapshot while retaining per-Goal Requested Time and Structure cells.

Refresh never saves, rebases or silently retries. Submission sets the context busy flag synchronously, so a second event before repaint cannot issue another command. Rejections keep intent and expected revision. Runtime acceptance is reported separately from durability; pending failure retains identity and uses only `retryGoalStructurePersistence`. Cancel clears unsaved intent rather than rolling back an accepted record. Late read/command continuations are checked against Goal, store and context; they cannot overwrite replacement views or initiate follow-up writes.

Related return restores both unrelated Goal and Structure drafts; native focus returns to the existing Goal title editor with a 3px outline. Review Schedule return retains the Structure form and Requested Time; Daily Planner return retains them and restores accepted-inspection heading focus. Save/Cancel focus intent returns to the Structure heading. Reduced-height native keyboard traversal moved from Milestone title to its optional date with visible 3px focus. Successful full restore/clear invalidates displaced context; rejected/aborted import and profile loading retain appropriate drafts. Tests distinguish controlled coordinator/runtime failure injection from actual native restore.
